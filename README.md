# Battle Royale: Number Elimination (Console Edition)

A command-line terminal game written in C where players compete in a number-elimination battle royale, choosing numbers within dynamically shifting safe zones until a winner is decided.

## Features
* Core algorithmic game engine built in standard C (`.c`).
* Automated bot choice generation and dynamic range calculation (`g1` and `g2`).
* Interactive console input and state management.

## How to Compile and Run
Open your terminal and run the following commands:

```bash
gcc retro-game-.c -o game
./game
