# 🎮 Battle Royale Console (C & Web Version)

A retro-inspired, command-line style Battle Royale number elimination game. Originally engineered in pure C with dynamic range calculations, dynamic player selection boundaries, and custom execution logic—now also adapted for instant web gameplay!

> **Note:** The original C core logic (`retro-game-.c`) was designed and written by **Siddharth**.
